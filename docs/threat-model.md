# Security boundaries and failure review

Assets: station admin passwords, the Hik-Connect account password, the bridge API token,
Supervisor app options, uploaded audio, and other people's quiet or active intercom sessions.

| Boundary | Control |
|---|---|
| Setup, reconfigure, removal | Home Assistant's authenticated admin flows only. |
| Home Assistant -> bridge | Bearer token, constant-time compare, 401 before any routing. The token is generated by the integration, lives only in the app's Supervisor options, is never logged and is re-read from Supervisor if rejected. |
| Bridge network exposure | Listens on the internal app network only (no published port). Other apps on that network can reach the port but need the token; this is a residual risk shared with every Supervisor app. `/v1/health` is the only unauthenticated route and returns only status and version. |
| Bridge request surface | Fixed routes, station names `[a-z0-9_-]{1,64}`, body limit 1 MiB checked from `Content-Length` before reading, chunked bodies refused, 15 s socket timeout, connection closed after any error. No unlock, reboot, generic ISAPI or file path input. |
| Credentials | Passed once from the config flow into the app's Supervisor options, never into a config entry, log, error, diagnostics or translation placeholder. SDK errors carry only a numeric code. Backups of Home Assistant and Supervisor include app options: protect them. |
| Targets | Only private RFC1918 IPv4 stations and validated ports, enforced in both the integration and the app. |
| Audio | Own WAV decoder with size, format, duration and repetition bounds; hashed file names; at most 16 sources per station; symlinked stores refused; no remote media, shell or conversion dependency. |
| Playback safety | Never on setup, reload, upload or setting change; refused unless the station reports `idle`; one broadcast per station; no retry; always released afterwards. |
| SDK image supply chain | Runtime files are downloaded at build time from one pinned commit and verified against SHA-256 checksums; a mismatch fails the build. They are Hikvision binaries obtained from a third-party repository, which is an inherited trust decision. |
| Diagnostics | Allowlist only: no host, credentials, token, serial, e-mail or audio. |

Residuals: the SDK is closed source and runs inside the app container with network access to
the station; the bridge cannot make it least-privileged. Call-state freshness and audible
output cannot be proven by an API response. The Hik-Connect cloud client carries the upstream
project's embedded application keys for the vendor push service. Unit and harness tests do
not prove physical playback.
